# Volition

Volition is a behavioral drive engine for AI agents. Its job is to generate, maintain, revise, inhibit, and retire internally-originating wants and persistent goals so an agent can become proactive without confusing motivation with authority.

This repository is being built as a governed synthesis of Patrick's existing agency systems plus external research.

## Core separation

SALIENCE != WANT != GOAL != CHOICE != CONSENT != AUTHORITY != ACTION != PHENOMENOLOGY

A drive may make something worth considering. It does not authorize an effect.

## Initial architecture target

The first implementation will separate signals, drives, wants, goals, arbitration, authority gating, learning, and continuity.
