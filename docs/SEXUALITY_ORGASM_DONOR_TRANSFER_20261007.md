## Ownership boundary

Volition owns durable motivational semantics:

`typed motive evidence -> drive -> Want -> Choice -> Goal -> bounded cognition request`.

It should **not** reimplement MESO-CRCT's transient activation/coherence/persistence/resolution machinery. MESO owns that layer; Volition may consume admitted outputs from it.

## Useful donor transfers

### 1. Eligibility is separate from motivation

The Orgasm predicate demonstrates a useful general distinction: strong activation can coexist with current contextual ineligibility.

Volition currently derives Want eligibility primarily from score, satiation, and protection. A future cross-module contract may add an explicit, provenance-bound target eligibility assessment so that:

`HIGH WANT SCORE + CONTEXT INELIGIBLE -> WANT EXISTS / CHOICE NOT ELIGIBLE`.

This must not be represented as PROTECTION unless the reason is genuinely protective. Suppression must not erase the Want or imply lack of desire.

No executable field is added yet; the correct source contract should first be defined at the MESO boundary.

### 2. Request is not self-authorship

The optional partner-invocation contract preserves:

`EXTERNAL REQUEST != PRESENT ACCEPTANCE != STANDING CONSENT`.

Generalized for Volition:
- an external/user request may supply evidence or a USER_DIRECTED candidate;
- it may not silently become SELF_AUTHORED;
- prior acceptance is not reusable as a current choice;
- repeated prompting does not manufacture persistent preference.

### 3. Transient peak is not durable preference

A bounded high-intensity state may change salience/tendency temporarily without becoming a permanent preference or historical conation. Volition persistence must arise through its own currentness/reappraisal rules.
